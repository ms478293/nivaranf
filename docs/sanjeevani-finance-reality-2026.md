# Project Sanjeevani Finance Reality

Date: March 6, 2026

## Bottom line

The current Sanjeevani finance model in the website code is not realistic enough for fundraising or strategic planning.

What is wrong with the current model:

- It treats `$7.50 per patient` as if it were the total program cost.
- It models only medicine and basic consultation cost.
- It does not properly price a roughly `50-person` organization with about `24 medical staff` plus operations, admin, logistics, and management.
- It does not separate annual operating cost from hospital construction and infrastructure cost.
- It presents a `~$2.44M` 2025-2030 rollout model that is far too low for the stated ambition.

The realistic fix is to split Sanjeevani into three finance layers:

1. Variable clinical cost
2. Fully loaded program operating cost
3. Capital buildout cost

Under that structure:

- Current two-team mobile operations are more likely in the `~$0.76M-$1.20M per year` range.
- A reasonable base case is `~$0.95M per year`, not `$247.5K`.
- The current all-in cost per patient is more likely `~$25-$36`, with a base case around `~$29`.
- If Phase III and Phase IV are literal, the full vision is not an `$18M total project`. It is a multi-decade, multi-partner, likely `tens to hundreds of millions of dollars` program.

## Realistic operating model for the current program

### What the old site model says

- Cost per patient: `$7.50`
- Annual budget for current two-team setup: `$247,500`
- 2025-2030 scale path: `$2.44M`

That model only works if Sanjeevani is basically:

- medicine distribution,
- light camp staffing,
- minimal admin,
- minimal transport,
- minimal overhead,
- no true organizational structure.

That is not the program you described.

### Current program structure that should be priced

This model assumes the current operating reality is closer to:

- `~50` total staff
- `~24` medical staff
- the rest in logistics, field support, admin, finance, monitoring, leadership, drivers, and coordination
- remote deployment in difficult terrain
- medicine and diagnostics distribution
- accommodation, food, travel, fuel, fleet, and equipment replacement
- compliance, insurance, reporting, and donor-grade operations

### Base-case annual budget

Using current Nepal salary and benefits signals, plus remote field logistics, a realistic current annual operating budget for the two-team model is:

- Payroll, loaded with statutory/benefit burden: `~$261K`
- Medicines and consumables at `~$7 per patient` for `33,000` patients: `~$231K`
- Fleet, transport, and fuel: `~$90K`
- Field lodging, food, and per diem: `~$85K`
- Equipment, diagnostics, and replacement: `~$80K`
- HQ/admin/IT/compliance/M&E: `~$80K`
- Training and clinical quality: `~$40K`
- Contingency: `~10%`

Base case result:

- Annual program budget: `~$954K`
- Cost per patient: `~$28.9`

### Reasonable operating range

For planning purposes, the current two-team system should be budgeted as:

- Lean case: `~$764K/year`
- Base case: `~$954K/year`
- Robust case: `~$1.20M/year`

That translates to:

- Lean case: `~$25.5/patient`
- Base case: `~$28.9/patient`
- Robust case: `~$36.5/patient`

## What `$7 per person` should mean

`$7 per person` can still be used, but only as:

- direct medicine and basic clinical consumable cost
- not total delivery cost
- not fundraising cost per patient
- not the all-in unit economics of the program

The website should stop showing `$7.5` as if it is the whole cost of care delivery.

Recommended terminology:

- `Variable clinical cost per patient`: `~$7-$9`
- `Fully loaded operating cost per patient`: `~$25-$36`

## What `$18M` can and cannot mean

### What `$18M` cannot honestly mean

`$18M` cannot credibly represent the direct all-in cost of:

- current mobile operations
- Phase II regional scale
- `77 hospitals`
- `1` central `700+` bed hospital

If the roadmap language is literal and Nivaran is the direct builder/operator, that number is far too low.

### What `$18M` can credibly mean

`$18M` can credibly be framed as one of these:

1. A multi-year Phase I and Phase II execution fund
2. A catalytic tranche for operations plus provincial hubs, referral, ambulance, and data systems
3. A seed fund that prepares later hospital phases for government or PPP co-financing

That is the version that can be defended.

## Realistic phase architecture

### Phase I: Mobile outreach and current scale-up

Scope:

- mobile camps
- medicine distribution
- basic diagnostics
- screening, referrals, prevention, outreach
- 2 to 5 medical teams over time

Planning view:

- current two-team budget: `~$0.76M-$1.20M/year`
- preferred base case: `~$0.95M/year`
- 2025-2030 realistic operating path: `~$7M-$9M`

This means the current site's `~$2.44M` rollout number is materially understated.

### Phase II: Regional hubs, response, and referral network

Scope:

- provincial or zonal bases
- vehicles and ambulance/referral support
- telehealth / EMR / live data systems
- medicine depots and cold-chain storage
- stronger emergency response and partner hospital integration

Planning view:

- one-time capex for hubs, vehicles, equipment, and systems: `~$2.5M-$4.5M`
- incremental multi-year operating lift: `~$5M-$9M`
- realistic phase envelope: `~$7.5M-$13.5M`

This is a planning estimate, not a tender-backed number. It is an operational design inference from the current staffing and deployment model.

### Phase III: 77-hospital network

Scope:

- local hospitals, not just mobile camps
- beds, equipment, staffing, commissioning, quality systems, procurement, utilities, and maintenance

What current public Nepal benchmarks imply:

- A `15-bed` hospital already sits around `~NPR 142M` in one current tender and `~NPR 180.68M` in a public benchmark study.
- At `~NPR 145/USD`, that is roughly `~$0.98M-$1.24M` per 15-bed hospital before a full all-in commissioning burden.

Simple civil-works benchmark:

- `77 x 15-bed hospitals`
- civil-works-only proxy: `~$75M-$96M`

More realistic direct-ownership planning range:

- after equipment, fit-out, commissioning, start-up, and reserves: `~$100M-$150M+`

This is the single biggest reason the old `$18M total project` idea does not work.

### Phase IV: Central 700+ bed hospital

Scope:

- tertiary or quaternary referral center
- major diagnostics
- emergency services
- likely teaching, specialist, and referral functions

Public Nepal benchmark signals:

- `400-bed` hospital estimate: `~NPR 2.74B`
- `1200-bed` hospital upgrade estimate: `~NPR 10.73B`

Using those public projects as a rough interpolation, a `700-bed` hospital plausibly implies:

- civil-works scale proxy: `~$33M-$43M`

Once equipment, specialist systems, fit-out, and commissioning are added, a more realistic direct-ownership planning range is:

- `~$40M-$70M`

This is an inference from public benchmark projects. It is not a direct tender number for a 700-bed Sanjeevani hospital.

## What the full vision probably costs

### If Nivaran directly owns and funds everything

Very rough planning range:

- Phase I: `~$7M-$9M`
- Phase II: `~$7.5M-$13.5M`
- Phase III: `~$100M-$150M+`
- Phase IV: `~$40M-$70M`

Total direct-ownership vision:

- `~$155M-$242M+`

### If Nivaran uses a partnership model for hospital phases

This is the more credible strategy.

Example structure:

- Nivaran directly funds Phase I and II
- Nivaran seeds pilot hospitals
- larger hospital expansion is financed through government, philanthropy, concessional debt, or PPP structures
- Nivaran focuses on design, management, quality, and systems integration rather than owning every asset outright

In that case, Nivaran's direct capital burden could be much lower:

- Phase I: `~$7M-$9M`
- Phase II: `~$7.5M-$13.5M`
- Phase III catalytic share: `~$15M-$40M`
- Phase IV catalytic share: `~$8M-$20M`

Total direct Nivaran envelope under a partnership strategy:

- `~$38M-$84M`

That is still much larger than `$18M`, but it becomes strategically believable.

## Recommended finance story for the website

The website should stop using a single blended number for everything.

Recommended public framing:

1. Current operations
   - patients served
   - camps completed
   - verified spend to date
   - variable clinical cost per patient
   - fully loaded operating cost per patient
2. Phase I scale plan
   - current annual operating need
   - 2025-2030 operating need
   - number of teams, patients, camps, and municipalities
3. Phase II readiness
   - hubs, ambulance/referral, telehealth, and logistics buildout budget
4. Long-term vision
   - hospital network and central hospital shown as separate capital phases
   - clearly labeled as partnership / infrastructure buildout, not current operating budget

## Recommended strategic position

The cleanest finance story is:

- `$7-$9` = variable clinical input per patient
- `~$25-$36` = fully loaded current cost per patient
- `~$0.95M/year` = realistic current two-team operating budget
- `~$7M-$9M` = realistic Phase I scale path through 2030
- `$18M` = possible Phase I plus Phase II execution and readiness fund
- hospital phases = separate capital strategy, likely requiring partnership and a much larger total envelope

## Immediate website changes that should happen

1. Replace the current `$7.5 per patient` headline with `variable clinical cost` wording.
2. Replace the current `$247.5K annual budget` with a realistic all-in annual operating range or approved base-case figure.
3. Replace the current `~$2.44M` rollout path with a realistic Phase I operating plan.
4. Stop implying that current tracking data covers hospital buildout economics.
5. Add a clear split between:
   - operations budget
   - infrastructure budget
   - partnership capital

## Recommendation

Do not force the whole Sanjeevani vision into a single `$18M` figure.

The defensible path is:

- treat `$18M` as a tranche, not the whole vision
- make Phase I and Phase II financially real
- show Phase III and Phase IV as separate capital programs
- decide whether hospitals are:
  - direct Nivaran assets, or
  - partnership / PPP / co-financed assets

That decision changes the total finance story more than any other assumption.
